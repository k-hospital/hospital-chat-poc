## 기능 설명

### 1. 병원 메인 화면 클론
실제 병원 홈페이지 메인의 레이아웃을 참고한 HTML 한 파일. 로고·기관명·문구·사진은 모두 가상 데이터("3팀 / 우리팀 챗봇 POC").
- 헤더 → 메인 비주얼 슬라이드 3장 + 빠른예약 바 → 소식 카드 → 미디어센터 → 새로운 소식(탭 필터) → SNS → 푸터
- PC는 섹션별 한 화면(`scroll-snap`), 모바일(375px)은 한 줄 배치
- 실제 기관의 로그인 화면 복제는 피싱 우려로 제외

### 2. 메인 화면 AI 상담 위젯
오른쪽 아래 **AI 상담** 버튼 → 챗봇이 메인 화면 위 창(420px, 모바일은 전체 화면)으로 열림.
- 처음 열 때 iframe을 불러와 메인 로딩을 늦추지 않음, ESC로 닫기
- 다른 버튼에 `data-chat` 속성을 붙이면 같은 창이 열림
- 불러올 챗봇: 배포 사이트 → 같은 사이트 `/chat/` / 내 PC → 개발 서버(`localhost:5173`), 없으면 실제 주소의 `/chat/`

### 3. 기능별 연결 주소 설정
챗봇 헤더의 ⚙ 버튼 → 메뉴마다 눌렀을 때 열릴 주소 등록. 항목은 config(메뉴 설정)에서 자동 생성.
- 묶음: 메인 메뉴 5 / 자주 찾는 질문 4 / 질문으로 여는 화면 1 / 상담 2
- `https://` 주소 또는 같은 사이트 경로(`/pages/...`)만 허용
- 저장: 브라우저 localStorage. 처음 여는 브라우저는 기본값(오시는 길, 증상별 진료 안내) 적용

### 4. 미연결 메뉴 회색 처리
연결 주소가 없는 메뉴(타일·진료 예약 배너·질문 칩·상담원 연결)는 회색, 누르면 "'메뉴명' 서비스는 준비중입니다".

### 5. 챗봇 안 페이지 이동
연결 페이지는 새 탭이 아니라 챗봇 안(PageViewer)에서 열리고 ← 로 복귀, 외부 사이트용 "새 창" 버튼.
- `public/pages/directions.html` 챗봇 디자인의 오시는 길 (약도, 주소 복사, 전화, 지하철·버스·자가용 탭)
- 챗봇 안에서 열리면 본문 제목을 숨겨 중복 방지

### 6. 병원 이름 변경, 헤더 반응형
"OO병원" → "우리팀 챗봇 POC"(프론트 목업, 백엔드 `/v1/config`, 탭 제목). 좁은 화면에서 이름·버튼이 줄바꿈되던 문제 수정, 400px 이하에서는 "AI 상담" 배지 숨김.

### 7. 공통 질문 입력 바, 질문으로 화면 이동
질문 입력창을 모든 화면 아래에 고정(설정 화면은 숨김)하고, 질문을 판별해 해당 화면으로 이동.

| 입력 예 | 판별 | 결과 |
|---|---|---|
| 배 아파, 속이 쓰려요 | 소화기 증상 | 증상별 진료 안내 이동, 추천 진료과 소화기내과 |
| 머리가 아파요 / 기침이 나요 | 두통 / 호흡기 | 같은 화면, 신경과 / 호흡기내과 |
| 가슴이 아파요, 숨이 차요 | 응급(최우선) | 이동하지 않고 응급 안내 + 119 전화 |
| 병원 위치 알려줘 | 오시는 길 | 오시는 길 이동 |
| 주차 되나요 | 주차 안내(미연결) | "준비중" |
| 안녕하세요 | 판별 실패 | "이해하지 못했어요" + 연결된 메뉴 칩 |

- 이동하면 말풍선은 닫히고 화면 위쪽에 "입력하신 내용"만 표시. 이동하지 않을 때만 말풍선
- 입력 문구는 postMessage로 같은 사이트 페이지에만 전달(건강 정보가 주소·로그에 남지 않게)
- 증상별 진료 안내(`public/pages/symptom.html`)는 샘플 문구 → 운영 전 의료진 검수 필요

### 8. 챗봇 창 끌어서 이동
메인 화면 AI 상담 창의 위쪽 바를 잡고 끌어서 이동. 위치는 브라우저에 기억, 바 더블클릭으로 원래 위치, 화면 밖으로 나가지 않음, 모바일(900px 이하)은 이동 없음.

### 9. 화면별 추천 질문 목록
입력창을 누르면 지금 화면에 맞는 추천 질문이 펼쳐지고, 고르면 바로 전송된다.

| 지금 화면 | 추천 질문 (기능 9 당시 기본 목록. 현재는 `frontend/data/suggestions.xlsx`에서 편집) |
|---|---|
| 메인 | 배가 아파요 · 머리가 아파요 · 기침이 나요 · 병원 어떻게 가요? · 주차 되나요? |
| 오시는 길 | 지하철로 가는 방법 · 버스 노선 알려주세요 · 자가용으로 가는 방법 · 주차 되나요? |
| 증상별 진료 안내 | 속이 쓰려요 · 머리가 아파요 · 기침이 나요 · 응급실 위치 알려줘 |

- 목록은 `frontend/src/shared/chat/suggestions.ts`에서 화면별로 관리. 목록이 없는 화면은 메인 목록 사용
- 연결 주소가 없는 기능의 질문도 표시하고, 누르면 "준비중입니다" 안내. 질문의 연결 기능이 알려진 기능인지·응급 문구가 아닌지 테스트로 보장
- 입력 중 걸러 보기: 띄어쓰기 무시, 글자가 순서대로 들어 있으면 일치("배아파" → "배가 아파요"), ↑↓·Enter·ESC 지원
- 키워드 보강: "병원 어떻게 가요?", "가는 방법", "길 알려줘", "응급실 위치" → 오시는 길. 지하철·버스·자가용 표현은 해당 탭 주제로 판별
- 같은 페이지에 새 질문이 오면 다시 불러오지 않고 전달 → 오시는 길에서 "버스 노선"을 고르면 버스 탭으로 전환
- 주차 안내 기본 연결: 오시는 길 자가용 탭(`/pages/directions.html#car`)

## 배포

1. 새 브랜치 → 커밋·push → PR → 머지
2. 최신 `main`에서 `cd frontend && npm run build:site -- --out <배포 폴더>`
3. Netlify 사이트 `ephemeral-parfait-e65ef8` → **배포(Deploys)** 화면에 폴더를 끌어다 놓기 (프로젝트 목록에 놓으면 새 사이트가 생김)
4. 실제 주소 확인. 문제가 있으면 Netlify 배포 목록에서 이전 배포를 **Publish deploy**로 되돌림
5. 다른 PC에서 올릴 때는 배포 폴더를 zip으로 묶어 압축을 풀지 않은 채 배포 화면에 놓는다. zip 안 경로는 `/`여야 한다(Windows PowerShell 5.1 `Compress-Archive`는 `\`로 저장해 Netlify에서 깨짐)

"Powered by Netlify" 배지는 Netlify 프로젝트 설정(General → Powered by Netlify badge)에서 끔.
