## 2. 질문 1건의 호출 흐름

```
질문(en/zh) ─► EXPAND_V1 ─► "KO: 번역문 / KW: 키워드"
                              │
              검색: dense+sparse(번역문+키워드) → 리랭커(번역문) → 상위 5개 자료
                              │
           ─► ANSWER_V5 (자료 + 원문 질문 + 마지막에 reply_rule) ─► 답변
                              │
              answer_problems(답변) 없음?  ── 예 ─► 반환
                              └ 있음 ─► REWRITE_LANG_V2 1회 ─► 반환 (그래도 남으면 경고 로그)
```
- 보통 LLM 호출 2회 (EXPAND + ANSWER). 표기 문제가 있을 때만 3회.
- `answer_problems()` (LLM 호출 없음, `translate.py`):
  - `lang=..` 답변 언어 ≠ 요청 언어 (괄호 안 한국어 병기는 빼고 문자 종류로 판별)
  - `traditional` 중국어인데 번체 전용 글자 2자 이상 (`_TRADITIONAL_ONLY` 약 60자)
  - `stray_hangul` 괄호 밖 한글 2자 이상
- 테스트(`tests/check_answer_lang.py`)도 같은 함수로 판정한다.

## 3. 프롬프트별 상세

### EXPAND_V1
- **입력**: system = 프롬프트 / user = 질문 원문
- **출력 형식**: 정확히 두 줄 `KO: ...`, `KW: ...` (형식이 어긋나면 첫 줄을 번역문으로 쓰고 키워드 없이 검색)
- **설계 이유**: 데이터는 병원 용어(수부외과·소화기내과)로 쓰여 있고 환자는 일상어(손목·속쓰림)로 묻는다. 번역만 하면 증상 질문의 약 절반을 놓쳐서 키워드 확장을 같은 호출에 넣었다 (추가 비용 거의 0, 0.3초 수준).
- **검증 (2026-10-01, `tests/check_symptom_hit.py`)**: 증상 25건 × 영어·중국어, 상위 5개에 기대 진료과 포함

  | 방식 | 진료과 적중 |
  |---|---|
  | 번역만 | 48% |
  | **번역 + 키워드 (EXPAND_V1)** | **100%** |

  (10-02 운영 데이터 814건 재적재 후에도 진료과 100%, 의료진까지 80~92%)
- 참고: `tests/check_symptom_hit.py`에는 검증 당시 프롬프트 사본(`EXPAND_PROMPT`)이 있다. 프롬프트를 바꾸면 그 사본도 맞춰서 재측정할 것.

### ANSWER_V5
- **입력**
  - system: 역할, "자료는 한국어지만 답변 전체는 {언어}로", 규칙(**병원은 항상 `hospital_name`으로 부를 것**·지어내기 금지·진단/병명/치료법 금지·**진료과·의사·지명·역·건물 등 한국어 고유명사는 모두 `번역 (한국어 원문)`, 괄호 밖 한국어 금지**), 증상 질문 답변 순서(진료과 → 의료진 → 내원 권유), 그 외 질문은 3~5문장 요약, **맨 끝에 `reply_rule`**
  - user: `[References]` 한국어 자료 → `[Question]` 원문 질문 → **맨 끝에 `reply_rule`**
- **reply_rule 예**: en `Answer in English only.` / zh `Answer in Simplified Chinese only. 请只用简体中文回答，不要使用韩文。`
- **V1 → V2 변경 (2026-10-06)**
  - 문제: `停车费是多少？`에 한국어로 답함 (4건 중 1건). V1은 언어 지시가 system 앞쪽에 한 번뿐이고, user 메시지가 한국어 자료 → … → `[Question in Korean]` 한국어 줄로 끝나서 모델이 한국어로 끌려감
  - 수정: user 끝을 그 언어로 쓴 `reply_rule`로 마무리, `[Question in Korean]` 줄 제거, system에 "괄호 병기 외 한국어 쓰지 말 것" 추가
- **V2 검증 (2026-10-06, `tests/check_answer_lang.py --repeat 2`)**: 중국어 5 + 영어 3 질문 × 2회 = **16/16 질문 언어로 답변**, 다시 쓰기(REWRITE) 작동 0회, 평균 2.5초·최대 4.6초
- **V2 → V3 변경 (2026-10-06)**: 병원 이름 번역이 실행마다 달라짐(国际圣玛丽医院 / 国际圣母医院) → `hospital_name` 고정, 중국어는 **国际圣母医院**. REWRITE_LANG_V1에도 같은 규칙 추가. 테스트에 중국어 병원명 검사 추가
- **V3 검증 (2026-10-06, `check_answer_lang.py --repeat 2`)**: 답변 언어 16/16, 다시 쓰기 0회, 평균 2.7초(첫 요청 8.1초). 중국어 10건 중 병원명 `国际圣母医院` 사용 9건, 다른 번역(圣玛丽 등) 0건.
  - **새 문제**: 중국어 1건(`怎么开诊断书？` 2회차)이 **번체자**로 답함(國際聖母醫院, 診斷書…). `detect_lang`은 간체·번체를 구분 못 해서 테스트·안전장치 모두 통과시킴 → 4장 참고
- **V3 → V4 변경 (2026-10-06)**: ① 중국어 `reply_rule`에 "只用简体字，不要使用繁體字" ② 지명·역·건물도 `번역 (한국어 원문)` 규칙, 괄호 밖 한국어 금지 ③ 안전장치 조건에 번체자·괄호 밖 한글 추가 (`answer_problems`), REWRITE_LANG_V1→V2
- **V4 검증 (2026-10-06, `--repeat 3`, 요청 제한 끈 테스트 서버)**: 질문 9개 × 3회 = **26/27 통과**, 평균 2.4초·최대 4.1초
  - 번체자 **0건**(중국어 15건), 중국어 병원명 고정 **15/15**, 다른 표기 0건
  - 실패 1건: `从机场到医院怎么走？` 2회차 — 괄호 밖 한글 2자 → 다시 쓰기 1회 작동했지만 **다시 쓴 뒤에도 2자 남음**. 남은 글자를 아직 확인 못 함(테스트가 답변 원문을 저장하지 않았음)
  - (같은 날 첫 시도는 3회차 7건이 백엔드 요청 제한 429에 걸림 → 테스트 서버는 `RATE_LIMIT_PER_MINUTE=0`으로 띄우도록 테스트 안내 수정, 429는 집계에서 분리)
  - 공항 질문 집중 재현(각 5회): 실패 원인 2가지 확인 — ① 모델이 역 이름을 반만 번역(`检암站`), 다시 쓰기로도 안 고쳐짐 ② 겹친 괄호를 검사 규칙이 인식 못 하는 오탐. **사용자 결정: 지명 용어집 안 만듦, 중국어 표기 개선은 여기서 중단** (두 한계는 남겨 둠)
- **V4 → V5 변경 (2026-10-06)**: 검색 설정 개선(후보 30·리랭크에 키워드)으로 맞는 전문의 조각은 대부분 들어오지만, 답변이 다른 부위 전문의를 고르는 경우가 있어 규칙 추가 — "증상 부위·내용과 전문분야가 맞는 의료진만 추천, 없으면 이름 없이 진료과만 (예: 손목 → 수부외과, 어깨·무릎·발목 전문의 금지)"
- **V5 검증 (2026-10-06, `tests/check_doctor_recommend.py --repeat 2`, 정형외과 손목·무릎·발목·어깨 × 영·중)**
  - **영어 8/8** 맞는 전문의, 다른 부위 전문의 0
  - **중국어 5/8**: 다른 부위 전문의 언급 2건(손목에 어깨·무릎·발목 교수 / 발목에 무릎 교수 함께), 이름 없이 진료과만 1건(어깨)
  - 답변 표기 회귀(`check_answer_lang.py`) 9/9 유지
  - 중국어 오추천은 중국어 개선 중단 결정에 따라 추가 조치 안 함 (기록만)

### REWRITE_LANG_V2
- **입력**: system = "사실·숫자·진료과·의료진은 그대로, {언어}로만, 한국어 고유명사는 모두 `번역 (원문)`, 괄호 밖 한국어 금지, 병원명 고정" + `reply_rule` / user = 처음 답변 + `reply_rule`
- **동작**: 1회만. 다시 써도 문제가 남으면 그 답변을 반환하고 경고 로그(`다시 쓰기 후에도 표기 문제 (요청 zh: stray_hangul)`)
- 로그 `rewritten=True` 건수로 작동 빈도를 볼 수 있다 (질문 본문은 로그에 남지 않음)
- V1→V2 (2026-10-06): 번체자·괄호 밖 한글도 고치도록 지시 추가

## 5. 프롬프트를 바꿀 때 절차

1. `prompts.py`에서 새 버전 이름으로 작성 (예: `ANSWER_V3`), 주석에 변경 이유
2. 이 문서 1장 표와 3장에 변경 이력 추가
3. 회귀 테스트
   - 답변 표기: `hospital_chatbot/tests/check_answer_lang.py --repeat 3` (백엔드를 `RATE_LIMIT_PER_MINUTE=0`으로 실행해 둘 것)
   - 검색 적중(EXPAND 변경 시): `hospital_chatbot/tests/check_symptom_hit.py`, `check_general_hit.py`
4. 결과를 이 문서에 기록
